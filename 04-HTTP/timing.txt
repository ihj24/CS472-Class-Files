Keep Alive showed an increased response time by about .308 seconds. The reason for the performance difference 
is that client-cc closes the connection with each request, meaning that this requires 3 full handshakes for 
each test. On the otherhand, Keep Alive only has to make one handshake per test. /delay/2 helps demonstrate 
this by forcing the server to wait 2 seconds before responding to help display the difference with bigger numbers.
